01
Lenguajes ↔ Datos

¿Cómo se conectan los lenguajes a una base de datos?

❯ Consigna del profesor

¿Cómo se conectan a una base de datos los lenguajes de programación C, C++, C#, JavaScript, Java, Python, HTTP, HTML y CSS?

Un lenguaje se conecta a una base de datos a través de un driver o conector: una librería que implementa el protocolo de la base. El patrón es siempre el mismo → importar driver → abrir conexión (host, puerto, usuario, contraseña, base) → enviar SQL → recibir resultados → cerrar.

C

C

Driver nativo · ODBC

Usa la API en C del motor (ej. la MySQL C API / libmysqlclient) o ODBC. Se incluye la cabecera, se abre la conexión con mysql_real_connect() y se ejecutan consultas con funciones en C.

C++

C++

Connector/C++ · libpqxx

Usa conectores orientados a objetos como MySQL Connector/C++ o libpqxx (PostgreSQL). También ODBC o la capa Qt SQL. Encapsula la conexión y las consultas en objetos.

C#

C#

ADO.NET · Entity Framework

Se conecta con ADO.NET y un proveedor (Microsoft.Data.SqlClient, MySql.Data). Usa una cadena de conexión y objetos Connection/Command. Su ORM es Entity Framework.

JS

JavaScript

Driver npm · Node.js

En el servidor (Node.js) usa drivers como mysql2 o pg, o un ORM como Prisma. En el navegador no se conecta directo a la BD: le pide los datos a una API por seguridad.

J

Java

JDBC

Se conecta mediante JDBC (Java Database Connectivity): una API estándar más un driver por cada motor. Hibernate y JPA son sus ORMs más usados.

Py

Python

DB-API 2.0

Usa módulos DB-API 2.0: mysql-connector-python, psycopg2 (PostgreSQL) o sqlite3 (incluido). SQLAlchemy y el ORM de Django son las capas más comunes.

Estos NO se conectan a una base de datos
<>

HTML

Presentación · Estructura

Lenguaje de marcado: estructura el contenido que ve el usuario en el navegador. No tiene lógica ni acceso a datos. Solo muestra la información que el backend ya obtuvo de la base.

{ }

CSS

Presentación · Estilos

Lenguaje de estilos: define colores, tipografías y layout. No ejecuta lógica ni se comunica con ninguna base de datos. Es puramente visual.

://

HTTP

Protocolo · Transporte

No es un lenguaje, es un protocolo. Es el "cartero" que transporta los request y response entre el navegador y el servidor. No se conecta a la BD: es el canal por donde viaja la petición.

Capa 1 Navegador HTML + CSS
(presentación)
Transporte HTTP request / response
(el cartero)
Capa 2 Servidor C# · Java · Python · JS
(lógica)
Capa 3 Base de Datos aquí se conecta
solo el backend

Las tres capas: presentación (HTML/CSS), transporte (HTTP) y lógica/datos (el lenguaje backend). De toda la lista, el único que realmente se enchufa a la base de datos es el lenguaje del servidor.

02
El ecosistema de datos

¿Qué son y cómo se conectan?

❯ Consigna del profesor

¿Cómo se conectan JsonServer, SQL, MySQL, PostgreSQL, Prisma7, Heidi, XAMPP, SQLite, MariaDB y Cassandra?

Cuidado: no todo en esta lista es una base de datos. Hay un lenguaje de consulta, motores relacionales, un motor NoSQL, un ORM, herramientas de gestión y hasta una API falsa. Clasificarlos es la clave para entender cómo encaja cada uno.

Lenguaje de consulta
SQL

SQL

Lenguaje · no es una BD

Structured Query Language. No es una base de datos, sino el idioma con el que se consultan las bases relacionales (SELECT, INSERT, UPDATE, DELETE). Lo hablan MySQL, PostgreSQL, MariaDB y SQLite.

Motores relacionales (SQL)
My

MySQL

Puerto 3306 · cliente-servidor

El RDBMS de código abierto más popular. Se conecta por el puerto 3306 con un driver desde cualquier lenguaje. Modelo cliente-servidor: hay un proceso del motor corriendo.

Ma

MariaDB

Compatible con MySQL · 3306

Un fork de MySQL hecho por sus autores originales. Compatible casi 1:1 (mismo protocolo y puerto 3306), así que se conecta exactamente igual que MySQL.

Pg

PostgreSQL

Puerto 5432 · objeto-relacional

RDBMS objeto-relacional avanzado, muy estricto con tipos e integridad. Se conecta por el puerto 5432 con drivers como pg (Node) o psycopg2 (Python).

lt

SQLite

Embebido · sin servidor

RDBMS embebido y sin servidor: la base entera es un único archivo .db. No hay proceso que levantar — te conectás abriendo el archivo. Ideal para apps locales y móviles.

Motor NoSQL
C*

Cassandra

Puerto 9042 · CQL · distribuida

Base NoSQL distribuida de tipo wide-column. Pensada para volúmenes enormes y alta disponibilidad repartida en muchos servidores. Se consulta con CQL (parecido a SQL) por el puerto 9042.

ORM (capa intermedia)
◭

Prisma 7

ORM · DATABASE_URL

Object-Relational Mapping para Node.js/TypeScript. Se ubica entre tu código y la base: definís un schema y Prisma genera un cliente type-safe que traduce a SQL. Se conecta con una cadena DATABASE_URL.

Herramientas
▦

HeidiSQL

Cliente gráfico · se conecta

Cliente gráfico para administrar MySQL, MariaDB y PostgreSQL. Se conecta a un motor que ya está corriendo para gestionarlo visualmente: ver tablas, ejecutar SQL, importar/exportar.

⛁

XAMPP

Entorno local · levanta el motor

Paquete que incluye Apache, MariaDB/MySQL, PHP y Perl. Su rol es levantar el motor de base de datos y el servidor web en tu propia máquina, sin configuración manual.

Mock API (no es una BD)
{ }

JSON Server

API REST falsa · por HTTP

Herramienta de Node que crea una API REST falsa a partir de un archivo db.json. No es una base de datos real: se usa para prototipar y simular un backend. Se "conecta" por HTTP (GET/POST a sus endpoints).

Manos a la obra

Código de conexión a la base de datos

❯ Consigna del profesor

Escribir el código necesario para la conexión a la DB para C#, JS, Python y JSON.

Cuatro formas de hacer lo mismo: abrir la conexión a una base tienda y leer la tabla clientes. Fijate que el patrón se repite en todos: conectar → consultar → recorrer → cerrar.

C# · ADO.NET

C#

Programa.cs
using MySql.Data.MySqlClient;

string cadena = "server=localhost;port=3306;user=root;password=secret;database=tienda";

using var conexion = new MySqlConnection(cadena);
conexion.Open();

var comando = new MySqlCommand("SELECT id, nombre FROM clientes", conexion);
using var lector = comando.ExecuteReader();

while (lector.Read()) {
    Console.WriteLine($"{lector.GetInt32(0)} - {lector.GetString(1)}");
}
JavaScript · Node.js

JS

conexion.js
const mysql = require('mysql2/promise');

const conexion = await mysql.createConnection({
  host: 'localhost',
  user: 'root',
  password: 'secret',
  database: 'tienda',
});

const [filas] = await conexion.query('SELECT id, nombre FROM clientes');
console.log(filas);

await conexion.end();
Python · mysql-connector

Python

conexion.py
import mysql.connector

conexion = mysql.connector.connect(
    host="localhost",
    user="root",
    password="secret",
    database="tienda",
)

cursor = conexion.cursor()
cursor.execute("SELECT id, nombre FROM clientes")

for (id, nombre) in cursor.fetchall():
    print(id, nombre)

cursor.close()
conexion.close()
JSON Server · API REST falsa

JSON

terminal

npm install -g json-server

#    { "clientes": [ { "id": 1, "nombre": "Ana" } ] }

# 3) Levantar la API REST falsa (puerto 3000)
json-server --watch db.json

// Conectarse = pedir los datos a la API por HTTP
const respuesta = await fetch('http://localhost:3000/clientes');
const clientes = await respuesta.json();
