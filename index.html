Definiciones

¿Qué es y para qué sirve?

01 ◭ ORM · Type-safe

Prisma v7

ORM moderno para Node.js y TypeScript. Ofrece un schema declarativo, migraciones automáticas y un cliente type-safe para bases de datos relacionales y no relacionales. Sirve para interactuar con la base de datos sin escribir SQL crudo.

02 ⬢ Runtime · V8

Node.js

Entorno de ejecución de JavaScript del lado del servidor basado en el motor V8 de Chrome. Sirve para construir aplicaciones de red escalables, APIs REST y servidores de alto rendimiento.

03 ▤ RDBMS · SQL

MySQL

Sistema de gestión de bases de datos relacional (RDBMS) de código abierto. Organiza datos en tablas con relaciones definidas mediante claves primarias y foráneas. Sirve para almacenar, consultar y gestionar datos de forma estructurada.

04 ⟶ Framework · HTTP

Express

Framework minimalista para Node.js. Sirve para crear servidores HTTP, definir rutas, manejar parámetros y encadenar middlewares de forma sencilla y organizada.

05 ⇄ Pipeline · req/res

Middleware

Función que se ejecuta entre la recepción de un request y el envío de un response. Sirve para autenticación, logging, validación de datos, manejo de errores y CORS. Puede modificar el request/response o pasar el control con next().

02
Comparación

Express vs Node Puro

Bajo nivel

Node.js puro

Requiere escribir manualmente el servidor HTTP con http.createServer, parsear rutas a mano, gestionar cabeceras y manejar cada request con código de bajo nivel.

server-node.js
const http = require('http');

const server = http.createServer((req, res) => {
  if (req.url === '/' && req.method === 'GET') {
    res.writeHead(200, { 'Content-Type': 'text/plain' });
    res.end('Hola mundo');
  } else {
    res.writeHead(404);
    res.end();
  }
});

server.listen(3000);
vs
Abstracción

Express

Abstrae esa complejidad. Ofrece routing declarativo, manejo de parámetros, integración de middlewares y respuestas simplificadas. Menos código, más estructura.

server-express.js
const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Hola mundo');
});

// routing declarativo + parámetros
app.get('/user/:id', (req, res) => {
  res.json({ id: req.params.id });
});

app.listen(3000);

HeidiSQL vs XAMPP

▦

HeidiSQL

Cliente gráfico para gestionar bases de datos MySQL, MariaDB, PostgreSQL y otros. Sirve para visualizar tablas, ejecutar consultas SQL, importar/exportar datos y administrar la BD de forma visual sin usar la línea de comandos.

⛁

XAMPP

Paquete de software que incluye Apache (servidor web), MySQL/MariaDB, PHP y Perl. Sirve para montar un entorno de desarrollo local completo en pocos minutos, sin configuración manual.
